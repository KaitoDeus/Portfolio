# MediCare Webapp

**Role:** Project Manager & Backend Developer  
**Timeline:** 01/11/2025 - 30/11/2025  
**Status:** Completed  
**Team Size:** 5

## 🌟 Overview

MediCare Webapp is a comprehensive healthcare web application developed to facilitate medical services and patient management. It provides a seamless user experience for booking appointments, managing health records, and interacting with healthcare providers. The frontend is built with React and Vite, while the backend utilizes modern web technologies to handle data and payments.

## 🚀 Key Features

- **Patient Portal:** A dedicated portal for patients to view medical records and manage appointments.
- **Online Booking:** Real-time scheduling system for doctor appointments.
- **Payment Integration:** Secure online payment processing for medical services using Stripe integration.
- **Responsive Design:** A fully responsive web interface optimized for both desktop and mobile devices.

## 🛠️ Technical Stack

- **Frontend:** React, Vite, Tailwind CSS, React Router DOM
- **Backend:** Node.js (Backend services)
- **Payment Gateway:** Stripe API
- **Tools:** ESLint, Swiper
