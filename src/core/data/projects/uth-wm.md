# UTH - Work Management (App Quản Lý Công Việc)

**Role:** Windows Forms Developer  
**Timeline:** 19/12/2024 - 10/02/2025  
**Status:** Completed  
**Team Size:** 4

## 🌟 Overview

UTH-WM is a desktop application designed for task and work management (App Quản Lý Công Việc). Built using C# and Windows Forms, it provides an intuitive interface for users to organize, track, and manage their daily tasks efficiently.

## 🚀 Key Features

- **Task Tracking:** Easily add, edit, and monitor the progress of various tasks.
- **User Authentication:** Secure login and registration forms for personalized task management.
- **Dashboard:** A central dashboard to view all ongoing and completed tasks.
- **Modern UI:** Clean and responsive desktop interface utilizing modern Windows Forms design principles.

## 🛠️ Technical Stack

- **Language:** C#
- **Framework:** .NET Framework
- **UI Toolkit:** Windows Forms, GDI+
- **Architecture:** Desktop Client-Server
